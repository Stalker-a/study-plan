# Учебный план — личный сайт

Каталог учебников из `C:\учеба\книги`, учебный план по уровням, прогресс, тесты после каждой темы, задачи из задачников и проверка уровня. Книги читаются прямо в браузере, в том числе на телефоне: сервер отдаёт страницы картинками, а последняя открытая страница запоминается.

Стек: Python + Flask + SQLite, рендер PDF через PyMuPDF, сервер waitress.

## Установка (один раз)

```bash
cd C:\работа\study-site
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env
```

Открой `.env` и придумай `SITE_PASSWORD` (от 8 символов, не пароль от другого сервиса).

## Запуск

Двойной клик по `start.bat`.

Сайт работает в фоне, без окна консоли. **Пока он запущен, в трее Windows (у часов, под стрелкой ˄) виден значок «У».** Нет значка — сервер не работает.

Меню значка (правый клик; двойной клик — открыть сайт):
- **Открыть сайт** — http://127.0.0.1:8000 в браузере;
- **Скопировать адрес для телефона** — адрес Tailscale в буфер обмена (пункт есть, если Tailscale подключён);
- **Открыть журнал** — `instance\server.log` с сообщениями и ошибками сервера;
- **Остановить сервер** — сервер останавливается, значок исчезает.

Чтобы значок был всегда на виду, перетащи его из-под стрелки ˄ на панель задач.

Отладка с окном консоли: `.venv\Scripts\python.exe app.py`.

### Автозапуск

В папке автозагрузки Windows лежит ярлык «Учебный сайт»: при входе в Windows он запускает сайт со значком в трее.

- Остановить: пункт «Остановить сервер» в меню значка или `stop.bat`.
- Отключить автозапуск: Win+R → `shell:startup` → удалить ярлык «Учебный сайт».
- Повторный запуск при уже работающем сайте ничего не сломает: он запишет в журнал, что порт занят, и завершится.

## Доступ с телефона через Tailscale

Сервер слушает только `127.0.0.1`, поэтому соседи по Wi-Fi его не видят. На телефон его выставляет Tailscale — это личная сеть только из твоих устройств.

1. Установи Tailscale на ноутбук (tailscale.com/download) и на телефон, войди в один и тот же аккаунт.
2. Один раз включи функцию Serve для своего tailnet (Tailscale сам даст ссылку при первом запуске команды ниже). Затем на ноутбуке, при запущенном сайте:
   ```bash
   tailscale serve --bg 8000
   ```
   Команда выведет адрес вида `https://имя-ноутбука.xxxx.ts.net` — открой его на телефоне. При первом запуске Tailscale может попросить включить HTTPS в настройках tailnet: следуй ссылке из вывода. Синтаксис `serve` менялся между версиями, проверь `tailscale serve --help`.
3. Отключить: `tailscale serve --https=443 off` (или `tailscale serve reset`).

Что важно знать:
- **Ноутбук должен быть включён и не спать**: Параметры Windows → Система → Питание → «Переводить в спящий режим» = Никогда (при питании от сети).
- **На телефоне одновременно работает только один VPN.** Tailscale — тоже VPN, поэтому, пока он включён, твой обычный VPN для зарубежных сайтов будет выключен, и наоборот. Работает ли Tailscale из Китая стабильно — не проверено, проверь на своей сети.
- **Запасной вариант:** телефон и ноутбук в одной Wi-Fi-сети, в `.env` поставь `HOST=0.0.0.0` и открывай `http://<IP ноутбука>:8000`. Тогда сайт увидят все в этой сети (защищает только пароль), и Windows может спросить разрешение для брандмауэра.

## Как пользоваться

1. **Проверка уровня** по каждому предмету (9 вопросов, три уровня сложности). Сайт посоветует, с какого уровня начать, и может зачесть темы ниже.
2. **Тема**: читаешь указанные главы (ссылка открывает книгу на нужной странице) → отмечаешь «Прочитал» → решаешь задачи из задачника и отмечаешь сделанные → сдаёшь тест (зачёт от 70%).
3. **Тема пройдена**, когда она прочитана и тест сдан. На главной видно, какую тему брать следующей и где ты остановился в книгах.

## Литература

Учебный план построен на 32 книгах. **Самих книг в репозитории нет**: большинство защищены авторским правом. Положи свои экземпляры в папку `BOOKS_DIR` (по умолчанию `C:\учеба\книги`), раскладывая по подпапкам предметов. Чтобы сайт узнал книгу, в имени файла должна быть строка из поля `match` в `content/curriculum.json`, например `Зорич - Математический анализ, часть 1`. Нумерация страниц в плане рассчитана на конкретные издания из списка.

## Как дополнять

- Учебный план: `content/curriculum.json`. Номера страниц — это номера страниц **в PDF-файле** (как в читалке), а не напечатанные в книге.
- Вопросы: `content/questions/<предмет>.json`. Типы вопросов:
  - `choice`: `options` + `answer` (номер правильного варианта с 0);
  - `number`: `answer` + необязательный `tol` (допуск);
  - `text`: `answer` — строка или список допустимых ответов.
- Новую книгу просто положи в `C:\учеба\книги`: она появится в каталоге. Чтобы сослаться на неё в плане, добавь её в `books` в `curriculum.json`.

Ошибки в JSON (неизвестная книга, неверный номер ответа, сломанная запятая) сайт покажет при запуске.

## Ограничения

- Читалка на сайте работает только с PDF. Файлы DJVU попадут в каталог, но их можно лишь скачать; чтобы читать на сайте, конвертируй их в PDF.
- Кнопка «PDF» открывает исходный файл в новой вкладке. Если Chrome его скачивает, проверь `chrome://settings/content/pdfDocuments` («Открывать PDF в Chrome»). На Android Chrome не показывает PDF сам, поэтому там читай во встроенной читалке сайта.
- Lutz описывает Python 2.6/3.0, основы актуальны. Strang (Linear Algebra and Its Applications) пока не разбит по страницам.
